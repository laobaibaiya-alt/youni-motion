# 交付契约

## 基础规格

- 画布：1920 × 1080，16:9。
- 帧率：30 fps。
- 每场独立生成并可独立复核。
- 中间场：交付 MP4，画面铺满全画布。
- 开场与尾场：交付 MP4 和带透明通道的 MOV。
- 单场项目同时视为开场与尾场，交付 MP4 和带透明通道的 MOV。

## 内部检查

交付前确认实际分辨率、帧率、时长、编解码可读性、透明通道、首尾帧、字幕同步、元素裁切、画布铺满、连续交互和安全区域。任何失败都先修复或给出具体阻塞，不要求用户提交校验字段。

输出命名应由内部场次顺序稳定生成，并与场景方案保持可追溯关系。用户可以按自然语言引用交付物。

## 模板命令

在初始化后的项目中：

```bash
npm run render:review
npm run render:alpha
```

Review 使用 H.264 MP4。Alpha 使用 PNG 中间帧、`yuva444p10le` 像素格式、ProRes 编解码和 4444 profile。两种输出必须来自共享场景实现，不能维护两套逐渐分叉的动画时间轴。

使用 `npm run validate:delivery -- <file> <review|alpha>` 调用 ffprobe 验证交付规格。该检查由 Skill 内部执行，不要求用户提供状态字段或校验凭据。
