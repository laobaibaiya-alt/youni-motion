# 交互动画方法论

## 从语义到物体关系

先识别当前句承担的演示任务：提出对象、建立并列、显示因果、执行合并、说明流程或给出结果。然后再选择卡片、标签、连接线、进度、容器等视觉对象。不要先选动效再套语义。

## 一个一个出现的组织方式

1. 主对象先出现，建立视觉锚点。
2. 次对象按口播顺序进入，使用相同运动语言但保留轻微时差。
3. 关系线在两端对象稳定后生长，并持续连接真实锚点。
4. 关系成立后才出现汇总、合并或输出对象。
5. 镜头结束前保留足够稳定阅读时间，再统一退场或衔接下一场。

## 动效基础要求

- 入场表达层级：主对象幅度更大，辅助对象更轻。
- 同组对象共享节奏，不同时抢占注意力。
- 连线和箭头由对象的动态锚点计算，运动期间连续更新。
- 元素不得只在关键帧位置正确；应检查整个持续区间的几何关系。
- 背景和全画布场景始终铺满，不因内部卡片容器缩小画布。
- 开场与尾场遵守人物安全区域，中间场可使用全画布叙事。
- 文字、形状、连接器和运动方向共同表达同一关系。

## 方案文档应说明

每场记录语义目标、对象列表、出现顺序、关系变化、运动方式、持续时间、稳定阅读区、退场方式、安全区域和交付格式。描述效果和约束，不复制固定案例。
