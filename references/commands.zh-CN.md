# 中文自然语言控制词

这些是语义类别，不是必须逐字照抄的命令模板。含义一致即可执行。

| 用户意图 | 常见表达 | 行为边界 |
|---|---|---|
| 查看与分析 | 看下、分析一下、对比一下、定位原因、和我讨论 | 只读检查，不生成、不覆盖 |
| SRT 初剪 | 清理字幕、先剪一下 SRT、去掉口头停顿 | 执行 `youniSrtCut` |
| SRT 精调 | 调整断句、重新分配时间、精调字幕 | 执行 `youniSrtRefine` |
| 场景切分 | 按语义分场、梳理连续场景、拆成动画段落 | 执行 `youniSceneSplit` |
| 动画方案 | 设计交互、梳理物体怎么出现、出动画流程 | 执行 `youniMotionPlan` |
| 生成场景 | 按方案生成、修改这一场、继续做下一段 | 执行 `youniMotionBuild` |
| 渲染交付 | 生成视频、渲染这一场、导出最终文件 | 执行 `youniMotionRender` |

范围可以来自“当前场、第一场、上一场、下一段、最后一场、刚才那段、00:10 到 00:18、字幕第 12 到 20 条、指定文件或唯一内容描述”。

当意图和目标都唯一时直接执行。只有真实歧义、真实缺失或需要用户做内容选择时才提问。
